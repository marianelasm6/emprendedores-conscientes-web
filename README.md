## Programa ORIGEN

### ¿Qué es?
Un programa grupal online de **8 encuentros semanales** de 2 horas cada uno, vía **Zoom**.

### ¿Qué incluye?
- 8 sesiones grupales semanales (2 hs c/u) por Zoom
- Sesión bonus sobre **mindfulness**
- Comunidad privada de **WhatsApp**
- Tareas semanales de integración
- Grabaciones de todas las clases

### Temáticas
1. Identificar bloqueos personales
2. Gestión emocional
3. Autoconocimiento y toma de decisiones
4. Transformación de patrones mentales
5. Desarrollo de hábitos sostenibles
6. Plan de acción post-programa

### Política de Satisfacción
Si participás de todos los encuentros y no quedás satisfecha/o, se ofrecen **3 sesiones individuales adicionales** sin cargo.  
*(No se realizan devoluciones de dinero.)*

**"Las 4 LEYES para conectar con tu PODER"**
